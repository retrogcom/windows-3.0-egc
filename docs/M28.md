# M28 Standard-mode compatibility

M28W3.COM is a DOS utility for Windows 3.0 DOSX.EXE on the Olivetti M28 /
AT&T PC 6310 with **BIOS 1.08**. It makes two corrections needed for this
Standard-mode configuration:

- A 17-byte BIOS return-frame correction.
- A 30-byte video-query correction that preserves ES:DI when the EGC colour
  startup leaves the card in its extended graphics mode.

**Do not apply this combined fix to BIOS 2.12 or an unverified BIOS version.**
The utility checks the DOSX routines and executable layout, not the BIOS.
A successful `/C` check therefore does not establish BIOS compatibility.
Real-mode Windows does not use DOSX.EXE.

## Check and apply

Exit Windows. Select the Windows drive and change to its SYSTEM directory.
Here `<WINDOWS>` means your Windows directory and `<DRIVER>` means the
extracted WIN16 directory. Replace the placeholders with actual paths.

```text
CD <WINDOWS>\SYSTEM
<DRIVER>\M28W3.COM /C
```

The check must accept both routines. If it refuses the file, stop and keep
the message; do not patch offsets manually. For a verified BIOS 1.08 system,
apply the correction:

```text
<DRIVER>\M28W3.COM
```

Continue only after it reports success or says both routines are already
patched. You can then start Windows with `WIN /S` from its main directory.
Do not run the utility from inside Windows. It requires an installed,
uncompressed DOSX.EXE; it does not patch compressed installation media.

## Backups and refusal messages

The utility backs up the pre-patch file as DOSX.B13. It writes and verifies
DOSX.NEW before renaming files, preserving the original length, timestamp
and attributes. It leaves any older DOSX.M28 backup intact.

When a change is needed, an existing DOSX.B13 or DOSX.NEW causes refusal.
Keep the backup; investigate a leftover temporary file before retrying.
Do not delete an existing backup merely to silence the message. A file with
both corrections already present is accepted without changes.

The utility finds unique instruction contexts. It does not depend on fixed
file offsets or accept an arbitrary executable with a matching filename.
The supported English and Norwegian Windows 3.0 layouts are recognized;
other layouts must pass the same checks.

## Undo the patch

Outside Windows, from its SYSTEM directory:

```text
COPY /B DOSX.B13 DOSX.EXE
```

Confirm replacement if asked. This restores the state immediately before
M28W3 was applied. Keep DOSX.B13 until Windows works again. Restoring the
colour driver with RESTORE.BAT is a separate operation and does not restore
DOSX.EXE automatically.
